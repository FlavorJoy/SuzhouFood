## 🔍 如何使用

### 方式一：直接浏览
1. 浏览下方的餐厅列表
2. 点击餐厅名称可查看高德地图详情
3. 点击 📖 展开查看详细信息

### 方式二：数据库查询
如需进行复杂查询，可以使用生成的SQL文件导入数据库：

```bash
mysql -u root -p < food.sql
```

### 方式三：关键词搜索
在浏览器中使用 `Ctrl+F` 搜索关键词（如："烧烤"、"火锅"、"湘菜"）
